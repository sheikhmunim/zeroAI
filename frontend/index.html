The cutoff applied to p(ai). It is a product decision, not a model property: at 0.99 the model is right 99.9% of the times it says “AI”, but misses 27% of AI images. It only changes the answer for images near the boundary — load the borderline sample (p(ai) 0.499, actually a real photo) and drag across 0.5 to watch the verdict flip.

Trained on CIFAKE: 32×32 images, all fakes from Stable Diffusion 1.4. Everything is upscaled 7× before the model sees it, which destroys the high-frequency artifacts real detectors rely on. Expect materially worse results on high-resolution images from modern generators. API docs
